# 美股指数定投决策看板

这是一个本地运行的个人投资数据看板，用来辅助判断纳指100和标普500相关定投策略的强度。它不是交易系统，也不是投资顾问工具；核心用途是把价格位置、趋势、宏观风险、市场情绪和仓位拥挤度放到同一个页面里，帮助你决定本期应该按 `0.8x / 1.0x / 1.2x / 1.5x / 2.0x` 哪个强度执行定投。

## 当前功能

- 纳指100 `NDX`：使用 Nasdaq 官方指数页面数据。
- 标普500 `SPX`：S&P DJI 官方自动抓取受限，当前使用 Yahoo Finance 民间源，并在页面明确标注。
- 宏观层：使用 FRED / New York Fed / BLS 等官方宏观数据。
- 今日策略建议：基于价格位置、趋势、情绪、宏观和估值压力打分。
- 情绪加权评分：结合恐贪指数、NAAIM 基金经理仓位、AAII 散户多空。
- 增强定投策略引擎：把上方模块综合成一个定投执行倍数。

## 运行方式

在项目目录执行：

```powershell
python server.py
```

然后打开：

```text
http://127.0.0.1:8000
```

健康检查接口：

```text
http://127.0.0.1:8000/api/health
```

主数据接口：

```text
http://127.0.0.1:8000/api/dashboard
```

## 刷新机制

后端缓存时间由 `server.py` 里的 `CACHE_TTL_SECONDS` 控制，当前为：

```python
CACHE_TTL_SECONDS = 60
```

前端也会每 60 秒请求一次 `/api/dashboard`。

注意：很多数据本身不是分钟级更新。例如 NAAIM 和 AAII 是周频，FRED 宏观数据也不是实时 tick 数据。页面每分钟刷新只是为了在数据源更新后能尽快反映，不代表所有指标每分钟都会变化。

## 数据源说明

### 指数与行情

- `NDX`：Nasdaq 官方 Index Overview 页面。
- `SPX`：Yahoo Finance 民间源。
- `VIX`：Yahoo Finance 民间源。
- `SPX 52周回撤`：由 Yahoo Finance 数据复算。
- `SPX 200DMA`：由 Yahoo Finance 1年日线数据复算。

### 宏观数据

- `EFFR`：FRED / New York Fed。
- `10年期美债收益率`：FRED / Federal Reserve H.15。
- `10Y-2Y 利差`：FRED。
- `美国失业率`：FRED / BLS。
- `Sahm Rule`：FRED。

### 情绪数据

- `Fear & Greed`：使用可抓取的 CNN Fear & Greed 镜像页。
- `NAAIM Exposure Index`：NAAIM 官方页面图表数据，通常周频更新。
- `AAII Sentiment Survey`：AAII 官网有防爬保护，当前使用较新缓存/转载缓存，并在页面标注状态。

## 缓存与回退

为了避免单个外部数据源临时失败导致整个页面不可用，后端对部分数据做了回退：

- Nasdaq 官方页面失败时，回退到最近一次已核验的 NDX 官方缓存。
- Yahoo Finance 失败时，回退到最近一次可用的 SPX / VIX 缓存。
- FRED 失败时，回退到最近一次已核验的官方宏观缓存。
- NAAIM 失败时，回退到最近一次缓存的周频数据。
- AAII 当前默认使用缓存，因为官网抓取不稳定。

页面会通过 `状态` 字段标注 `官方在线`、`官方缓存`、`民间源在线`、`民间源缓存`、`民间转载缓存` 等状态。

## 策略模块

### 今日策略建议

该模块根据以下因子打分：

- 价格位置：SPX 相对 52 周高点的回撤。
- 趋势位置：SPX 相对 200 日均线的偏离。
- 市场情绪：VIX。
- 宏观风险：10年期美债、失业率、Sahm Rule。
- 估值压力：可得的 SPX TTM 市盈率。
- 结构广度：NDX 与 SPX 当日涨跌差。

输出内容包括：

- 综合建议
- 综合分
- 分项评分
- 当天分析思路
- 执行计划
- 风险提示

### 情绪加权评分

该模块使用逆向定投视角评分：

- 恐贪指数，权重 `40%`
- NAAIM 基金经理仓位，权重 `35%`
- AAII 散户多空，权重 `25%`

评分逻辑大致是：

- 越恐慌，越支持加仓。
- 基金经理仓位越低，越支持逆向加仓。
- 散户越悲观，越支持逆向加仓。
- 如果恐贪和 NAAIM 同时偏热，则压低额外加仓建议。

### 增强定投策略引擎

该模块综合今日策略建议和情绪评分，给出定投倍数：

- `0.8x 减少追加`
- `1.0x 正常定投`
- `1.2x 小幅加强`
- `1.5x 加强定投`
- `2.0x 强力分批加仓`

核心原则：

- 基础定投不断供。
- 回撤越深，定投强度越高。
- 恐慌越强，逆向加仓分越高。
- 仓位和情绪过热时，不额外追买。
- Sahm Rule 触发或宏观风险升高时，强制降档。

## 当前注意事项

- 这个项目依赖公开网页和公共接口，外部页面结构变化可能导致解析失败。
- AAII 没有稳定免费公开接口，当前不是完全自动周更。
- S&P DJI 官方实时数据通常属于授权数据，当前没有接入官方授权接口。
- 本项目不做交易执行，只输出定投强度建议。
- 所有策略建议都只是规则化辅助，不构成投资建议。
